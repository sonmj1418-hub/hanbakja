# Focus on 앱 정리

이 문서는 이 저장소에 있는 Focus on 앱을 기준으로 합니다. 설치 이름과 웹 제목은 **Focus on**, 패키지는 `app.hanbakja.shorts`, `package.json` 버전은 **0.7.0**입니다. 기록은 이 앱의 기존 히스토리 위에 있습니다.

친구에게 받았던 ShortsAI(`app.focuson.shorts`, 네이티브 밴드잇·공부 카드·몇 분 약속) 트리는 이 저장소가 아닙니다. 그 트리를 통째로 넣으면 이 앱의 파일을 덮어쓰게 되어, 여기에는 올리지 않았습니다. 릴스 개입은 이 앱이 이미 쓰던 쇼츠 팝업과 같은 시트로 맞춰 두었습니다.

## 이 앱이 하는 일

YouTube Shorts 또는 Instagram Reels 플레이어가 열리면 영상을 멈추고, 오늘 누적 사용량으로 개입 세기를 정합니다. 흐름은 **감지 → 이유 → Level 1~3 → 기록 → 통계·일일 리포트**입니다. 기록은 기기 안에만 둡니다. 화면 글, 메시지, 비밀번호, 계정은 읽지 않습니다. 계정, 서버, API 키는 없습니다.

오늘 누적 시간으로 Level을 나눕니다. 기본 경계는 10분과 20분이고, 설정에서 바꿀 수 있습니다.

| 오늘 누적 | Level | 개입 |
|---|---|---|
| Level 2 시작 미만 (기본 10분) | 1 | 이유 → 5초 대기 → 보기 또는 나가기 |
| Level 3 시작 미만 (기본 20분) | 2 | 이유 → 물 마시기, 스트레칭, 독서, 걷기, 눈 쉬기, 호흡 중 하나 → 다시 볼지 |
| 그 이상 | 3 | 경고 후 이번 시청 종료, 또는 10·20·30·60분 차단 |

아이폰은 다른 앱을 막지 못합니다. 홈 화면에 추가하는 웹 앱으로 연습만 할 수 있습니다.

## 화면

하단(넓은 화면은 왼쪽)에 네 칸이 있습니다. `/watch`만 탭 없이 전체 화면입니다.

- **홈 (`/`)**: 오늘 누적, Level, 다음 경계까지 남은 시간. **쇼츠 열기**는 연습 피드입니다.
- **통계 (`/stats`)**: 최근 7일. 날짜를 누르면 그 날의 사용, 이유, Level, 차단.
- **리포트 (`/report`)**: 하루 요약. 설정한 시각(기본 21:00)이 지나면 오늘의 리포트입니다.
- **설정 (`/settings`)**: 개입 스위치, 접근성 안내, Level 경계, 리포트 시각, 알림, 기록 초기화.
- **개입 (`/watch`)**: 연습 피드가 쓰는 웹 개입. YouTube Shorts와 Instagram Reels는 이 화면으로 앱을 전환하지 않고, 플레이어 위에 뜨는 오버레이가 같은 개입을 엽니다.

## 실제로 개입이 열리는 길

접근성 서비스가 YouTube와 Instagram 창만 봅니다. 판별은 화면 ID와 클래스 이름입니다. 쇼츠 플레이어가 아니고 롱폼이면 쇼츠로 보지 않습니다. 홈, 검색, 일반 영상, Instagram 피드와 스토리는 건드리지 않습니다.

**YouTube Shorts와 Instagram Reels**

둘 다 같은 네이티브 오버레이 시트입니다. 앱을 앞으로 가져오지 않습니다.

1. 진입하면 오디오 포커스를 잠시 가져오고 미디어 일시정지를 보냅니다. 플레이어는 그 자리에 둡니다.
2. 오늘 누적으로 Level을 정하고, 이유 질문부터 같은 단계를 띄웁니다. Level 2의 대체행동에는 호흡이 있고, Level 3에서는 시간 차단을 고릅니다.
3. 릴스 시트의 제목·안내·보기 버튼·차단 문구는 **릴스**입니다. 쇼츠 시트의 같은 자리는 **쇼츠**입니다.
4. 개입 스위치가 꺼져 있으면 시트를 띄우지 않습니다. 접근성 서비스는 그대로 두어도 됩니다.
5. 나가기나 차단을 고르면 시트만 닫고, 그 플레이어에서만 뒤로 갑니다. YouTube나 Instagram 전체를 그때 종료하지 않습니다.
6. 보기를 고르면 시트를 닫고 멈춘 영상을 다시 재생하며, 그 화면에 머문 초를 기록합니다.

서비스가 연결될 때 예전에 앱 안 `/watch`로 넘기려고 쌓아 둔 대기 대상은 지웁니다. 새 감지로는 그 화면을 열지 않습니다.

**연습 피드**

홈의 쇼츠 열기는 예전 웹 흐름입니다. 대상 앱이 없으므로 문구는 쇼츠로 남아 있습니다. 시청을 고르면 앱 안의 가짜 피드가 돌아가고, 그 시간은 이 기기의 사용 기록에 더해집니다. 피드 안의 “쇼츠 1”, “다음 쇼츠”는 연습 화면이라 바꾸지 않았습니다.

리포트 알림 제목은 시트가 아닙니다. `오늘의 Shorts 사용 리포트` 그대로입니다.

## 데이터가 있는 곳

브라우저는 `localStorage` 키 `hanbakja.v1`입니다. 안드로이드 웹뷰도 같은 키를 씁니다. SQLite 데이터베이스는 없습니다. 네이티브 대기열, 잠금 시각, 오늘 시청 초는 접근성 서비스의 SharedPreferences `hanbakja_guard`에 잠깐 있습니다. 웹이 1.5초마다 초를 가져간 뒤 그 칸을 비웁니다.

| 키 | 내용 |
|---|---|
| `usageLogs` | 시작·끝, 초, 클립 수. 날짜는 기기 로컬 날짜 |
| `interventions` | 시각, Level, 이유, 대체행동, 재실행, 차단, 결과 |
| `activeSession` | 지금 재생 중인 연습 또는 이어보기 |
| `block` | 차단이 끝나는 시각과 고른 분 |
| `settings` | Level 경계, 리포트 시각, 알림 스위치 |

기록 초기화는 사용·개입·세션·차단을 지웁니다.

알림은 서버 없이, 앱이 열려 있을 때의 브라우저 알림입니다. 매일 리포트 시각에 하루 요약을 보냅니다.

## 중요한 모듈

웹

- `components/store.tsx`: 화면 상태. 바꿀 때마다 `hanbakja.v1`에 씁니다.
- `components/guard-bridge.tsx`: 1.5초마다 네이티브 시청 초를 받아 옵니다. 플레이어 시트는 여기서 `/watch`를 열지 않습니다.
- `components/intervention-flow.tsx`: 이유와 Level 단계. 시트 문구는 `lib/sheet-copy.ts`가 릴스와 쇼츠를 나눕니다.
- `components/guard-panel.tsx`: 개입 스위치와 접근성 안내.
- `lib/logic.ts`: Level, 통계, 리포트 문장.
- `lib/guard.ts`: 웹↔네이티브 플러그인. 이름은 `HanbakjaGuard`입니다.

안드로이드 `app.hanbakja.shorts`

- `ShortsGuardService`: 접근성. 감지, 멈춤, 시트, 나가기, 시청 초.
- `ShortsPopup`: 플레이어 위 오버레이. 쇼츠와 릴스가 같은 창을 씁니다.
- `GuardSheet`: 시트를 쓰는 대상은 `youtube`와 `instagram`뿐입니다.
- `GuardScreens`: 쇼츠/릴스 판별.
- `GuardState`: 대기열, 시청 초, 개입 스위치.
- `GuardPlugin`: 웹 연결.
- `MainActivity`: 앱 실행. 플러그인을 등록합니다.

스택은 TypeScript + Next.js 16, React 19, Capacitor 8, Java 접근성 서비스, Gradle입니다. 다른 앱을 막는 설치본은 안드로이드만입니다.

## 소스에서 보이는 거친 부분

실행해서 재현한 버그는 아닙니다. 코드를 읽어 보이는 어긋남입니다.

- **이름이 두 갈래입니다.** 설치 이름과 웹 제목은 Focus on이고, `package.json` 이름·저장 키·플러그인은 hanbakja입니다.
- **연습 피드는 시트와 다릅니다.** 홈의 쇼츠 열기는 플레이어 위 팝업이 아닙니다. 문구도 쇼츠로 남아 있습니다.
- **쇼츠·릴스 판별은 화면 ID입니다.** YouTube나 Instagram이 화면 구조를 바꾸면 감지가 어긋날 수 있습니다.
- **영상 멈춤은 오디오 포커스와 미디어 일시정지입니다.** 폰에 따라 영상이 계속 재생될 수 있습니다. 쇼츠와 릴스가 같은 방법입니다.
- **릴스 시트는 폰에서 열어 보지 않았습니다.** 단위 테스트는 쇼츠와 릴스가 같은 시트 주소와 마커를 쓰고, 문구만 갈라지는지 확인합니다.
- **서명된 설치 파일은 이 변경에 없습니다.** 받는 주소의 APK는 이전 디버그 빌드입니다. 소스의 릴스 시트는 다시 빌드해야 설치본에 들어갑니다.
- **웹 개입 화면은 그리는 도중에 상태를 넣습니다.** `components/watch-view.tsx`가 첫 사용량을 렌더 중에 저장합니다.
- **이 앱에는 밴드잇, 공부 카드, 몇 분 약속, 작은 창(PIP) 처리가 없습니다.** 그 기능은 친구 쪽 ShortsAI 정리에만 있었고, 이 저장소의 Level 흐름으로 바꾸지 않았습니다.
